# 0010 — RBAC composable, par périmètre et par propriété

## Context

Équipes, prestataires et filiales n'éditent que leur portion ; la classification de
sécurité ne doit être modifiable que par qui en a le droit. Décisions D36 ; 003/P6, P7.

## Decision

Permissions déclarées par les modules (dont une permission par propriété) ; rôle =
ensemble de permissions ; liaison = sujet × rôle × périmètre (entité, site, domaine,
sous-arbre de préfixes), héritée vers le bas. Une écriture exige le droit sur les objets
visés et sur chaque changement de valeur résolue qu'elle provoque. Les politiques
d'approbation s'expriment dans le même modèle. Le filtrage des listes par droits est
traduit en prédicats SQL.

## Alternatives

- Rôles fixes : trop grossiers pour prestataires et équipe sécurité.
- Moteur externe (OPA, Cedar) : filtrage de listes de 10⁶ objets coûteux ; envisageable
  plus tard comme adaptateur.

## Consequences

- Chaque objet doit avoir une ancre de périmètre résoluble rapidement.
- Le contrôle sur les effets indirects dépend du différentiel (ADR 0008).
